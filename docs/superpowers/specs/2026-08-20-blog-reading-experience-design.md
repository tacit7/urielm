# Blog Reading Experience

## Goal

Turn the published post into a calm, legible reading experience that feels consistent with the Tokyo theme and the shared content-card system.

## Article detail

- Use a centered reading shell capped near 70 characters with consistent mobile gutters.
- Present a compact back link, category eyebrow, strongly tracked title, optional excerpt/dek, and a metadata row containing date, calculated reading time, and author label.
- Keep the Markdown body semantic and improve hierarchy through the shared prose styles, especially paragraph rhythm, headings, lists, links, blockquotes, and code. Quotes and callouts use a quiet full outline with no left-border treatment.
- End every article with a quiet continuation panel and a clear link back to the blog index. Keep older/newer navigation when neighboring posts exist.

## Blog index

- Use the same page shell and header hierarchy as the reader.
- Give the post collection a stable DOM region and stable IDs for each article card.
- Replace the bare empty-state sentence with a bordered, theme-aware empty surface.

## Responsive and accessibility behavior

- Preserve a comfortable line length while reducing title and body size on narrow screens.
- Metadata wraps without overflow, navigation labels remain descriptive, and focus behavior stays native to links.
- No essential information depends on color or motion.
