# Q&A and Final Recommendations

Time range: 71:45-end

The closing Q&A focuses on practical ways to turn the Claude-driven creative strategy workflow into an ongoing testing system. The presenter recommends keeping tests manageable by prioritizing the highest-impact variables first, especially hooks, formats, and angles, and scaling the number of variables only as budget increases. For planning, Claude needs the brand context, core avatar, budget, and desired outcomes; from there, it can help structure a 30-day creative testing plan, though it cannot fully replace ad production.

The final recommendations cover adapting the workflow across languages, analyzing winners and losers, targeting in Meta, and choosing supporting tools. The presenter suggests translating prompts or using Meta's built-in AI translation cautiously, judging ads after roughly 3-5x the target CPA in spend, letting broad consumer creative guide Meta's targeting, and using uploaded prospect lists for narrow B2B audiences. For tooling, Atria is recommended for Instagram ad research, Gemini and ChatGPT for images, Claude Design for text-heavy visuals, and Higgsfield for short video clips.

- Test more variables only when the budget can support the added complexity.
- Always create multiple hooks for each ad concept because hook testing adds little production cost.
- Prioritize testing hooks, formats, and angles before expanding into a large matrix of offer, spokesperson, CTA, and other variables.
- A 30-day testing plan should be based on brand context, core avatar research, budget, and the target performance goal.
- For non-English audiences, either prompt Claude in the target language or use Meta's AI translation features, then review quality carefully.
- Analyze creative performance by labeling ads around key variables and asking Claude to identify which combinations are winning.
- Use spend thresholds relative to target CPA; a rough guideline is 3-5x target CPA before deciding whether to scale, iterate, or kill an ad.
- For broad consumer products, Meta can often find the right audience through the creative itself; for narrow B2B, upload a defined prospect list.
- Recommended tools include Atria for ad research, Gemini or ChatGPT for images, Claude Design for text-based visuals, and Higgsfield for short clips.
