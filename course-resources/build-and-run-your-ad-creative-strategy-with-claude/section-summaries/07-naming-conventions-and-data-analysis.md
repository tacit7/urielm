# Naming Conventions and Data Analysis

Time range: 59:25-71:45

This section explains why ad naming conventions matter before ads are launched. Each ad should be labeled with enough structure to preserve the core creative variables: persona, angle, offer, and format. By naming ads this way in Meta, Claude can later analyze performance data through the Meta MCP server and identify which variables, or combinations of variables, are driving results rather than merely showing which individual ad won.

The instructor then demonstrates how a data flowchart prompt can turn labeled ad performance into a readable breakdown by persona, angle, offer, and format. In the example, the winning combination is identified by looking for the ad path with the strongest spend signal and lowest cost per lead or action. The Q&A extends this into diagnostic analysis: poor performance should be traced through the funnel using metrics like CPM, thumb-stop rate, playthrough, click-through rate, and landing-page conversion rate, with the first weak metric indicating the area to fix.

- Label ads before launch so later analysis can explain why performance happened, not just what performed best.
- Use a consistent naming structure that captures the concept name, persona, launch date, and the key creative variables.
- The four core creative variables for analysis are persona, angle, offer, and format.
- Claude can use labeled Meta data to generate flowcharts that reveal winning variable combinations.
- Without structured naming, ad reports may show spend and outcomes but lose the strategic context behind each creative.
- Diagnose weak ad performance as a funnel: CPM, hook or thumb-stop rate, playthrough, click-through rate, and landing-page conversion.
- Testing scope should match budget; lower budgets should test fewer variables with more attention to production quality.
- Hooks are usually efficient to test because multiple hook variations can be recorded during the same production session.
