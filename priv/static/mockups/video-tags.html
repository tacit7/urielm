Agents
Selected-tag behavior: clicking Tags opens a checkbox-style panel; selecting Agents and pressing Apply pushes ?tag=agents onto the URL (comma-joined for multiple, e.g. ?tag=agents,career), merging with whatever q and format params are already present — the same pattern VideosLive uses for format today.
  • The button switches to its active style and shows a count badge for the number of selected tags.
  • An "Active" chip row appears under the toolbar; each chip's ✕ removes just that tag, and "Clear all filters" resets q, format, and tag together.
  • Filtering happens server-side, same as search/format: the featured video is recomputed as the first matching standard video, and empty sections (no full videos, no shorts) simply don't render — matching the existing standard_empty? / shorts_empty? assigns.
  • If a filtered combination produces zero results across both sections, the existing "No videos found" empty state (see videos-discovery.html) reuses as-is, with copy adjusted to mention the active tag.

Mobile behavior: the Tags button sits in the same horizontally-scrollable row as the format pills. Tapping it opens a bottom sheet (shown here already open, over a dimmed backdrop) instead of the desktop dropdown — same options, same single-tag-per-chip model, same ?tag= URL sync. Apply closes the sheet and pushes the new query string via a LiveView patch, so the format pills, search box, and scroll position all persist. Tapping the backdrop or the handle also dismisses the sheet without applying changes.

Video detail behavior: tags render as a labeled row directly beneath the byline, above the description panel — the same badge component used on cards, sized up slightly and made clickable. Clicking a tag navigates to /videos?tag=agents, landing back on the library pre-filtered exactly as in the "Desktop · tag selected" view, so tags double as lightweight related-content navigation without a separate "related videos" feature.
